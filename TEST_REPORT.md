### Endpoint changes recorded

- **DefiLlama**: the specification lists `https://api.llama.fi` as the free base.
  On 2026-10-04 `api.llama.fi/prices/current/...` returns 404; the documented
  price routes are served by the official free coins host `https://coins.llama.fi`.
  The adapter uses `coins.llama.fi`; no Pro endpoint is used.
- **DefiLlama chart** (`/chart/{coin}?start&span&period=1d`): one request may
  return at most 500 points (coins × span), so history is fetched in windows of
  at most 499 days, newest first. Prices arrive as JSON floats and are converted
  to exact decimals from their shortest text form.
- **Zerion**: an address that is still being indexed answers HTTP 202; it is
  treated as "loading", never as an empty wallet. Throttling (`429 Too many
requests`) was observed at about 2 requests/s, below the advertised 3/s, so the
  adapter paces at 1 request/s.
- **Zerion positions** report native assets with `address: null`, transactions
  with `address: ""`; both map to the native asset.
- **Zerion on Polygon** reports native POL under the system contract
  `0x…1010`; it is mapped to the native asset.
- **Live Coin Watch**: Toncoin's code is `TONCOIN`; `TON` is an unrelated coin.
- **DefiLlama** keys TON Jettons by the bounceable friendly address, not the raw
  `0:…` form; responses are matched to the requested id, not lowercased, because
  Solana and TRON contracts are case-sensitive.
- **TronGrid** returns TRC-20 balances without decimals; metadata comes from
  history or a bounded lookup (10 tokens per sync). `only_confirmed=true` is used
  for both lists, and `ret[0].fee` is the authoritative fee.
- **TonAPI** event pages end when `next_from` is 0 or the page is empty; an event
  with `in_progress` is re-read by id until final.

## Known limitations of this stage

| Limitation                                                                        | Status / next step                                                                            |
| --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Daily historical prices come from DefiLlama only                                  | Live Coin Watch history is not used for charts yet; another source can be added in stage E.   |
| Period return is `—` while any held asset in the scope has no price               | As ACCOUNTING.md requires when prices are missing. The known parts stay visible.              |
| Bridges, staking, LP positions and other partially decoded activity               | Kept as observations and listed for review; no economic interpretation is invented.           |
| Per-network provider limits (TRC-10, TON contract calls, DeFi positions)          | Listed in Settings → Networks and [docs/NETWORK_COVERAGE.md](docs/NETWORK_COVERAGE.md).       |
| New TRON/TON native addresses are verified live but not on a native desktop run   | The native Linux run in this report is the stage C build; stage E repeats it on Windows.      |
| Zerion "trash" transactions (address poisoning, spam airdrops) appear in Activity | Spam tokens are excluded from totals and accounting; hiding spam activity belongs to stage E. |
| Unverified tokens with a DefiLlama quote count toward the total                   | They are labeled "unverified"; a review/hide control is stage E.                              |
| CSV export of lots and decisions, backup/restore                                  | Stage E.                                                                                      |
| Bitcoin: single addresses only, no xpub                                           | By specification (v1).                                                                        |
