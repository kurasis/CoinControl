They enable the console through Settings, restart the app, observe actual Esplora HTTP 200 responses and measured response times, reject URL paths or wallet addresses in console output, and exercise pause, clear and disabling. The [inspected native screenshot](network-console-live.png) contains actual existing public BTC/DefiLlama requests, including failed offline connections. No extra API calls are made specifically for diagnostics. Native public usage: Esplora 12 / DefiLlama 14 requests, both within the unchanged 50-request ceiling. Cancellation feedback: 226 ms.

Deterministic regressions verify pending/HTTP retry/RPC error entries, secret exclusion even for short keys, the 500-entry bound and clearing while requests finish. Old settings preserve language, theme, privacy, timezone and intervals with the new toggle defaulting off. Sync outcomes distinguish partial/error/cancelled/failed, and early returns clear the running state. Connection probes no longer acquire their already-held sync lock twice. React tests cover background state across navigation, opt-in polling, 50-row pages, RPC errors, filtering and controls.
